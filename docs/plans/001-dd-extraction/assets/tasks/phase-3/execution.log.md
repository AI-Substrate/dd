## tk-0005 — the pack gate (released mid-run by o-prime)

Commit `dcf6f1e`. `scripts/pack-gate.sh`, wired as `just pack-gate` and a CI step — one script, so
CI and local cannot drift into testing different things. Deliberately NOT in `just checks`: it
clones and installs, ~1 minute, the wrong shape for the inner loop.

Seven steps, all passing: clean clone of HEAD (asserting no `dist/`, no `node_modules/`, so
`prepack` cannot be credited for someone else's work) → `npm ci` → `npm pack` → file-list
assertion → `--omit=dev` install → the installed bin against a fixture corpus → every claimed verb
answers `--help`.

The jiti proof runs **through the tarball**: an adapter in untranspiled TypeScript turns `2610`
into `**43h 30m**` in the rendered markdown, which is only possible if the shipped `jiti` did the
transpiling. dw-0005 asks for an assertion that fails when the fixture is absent, so the gate runs

## Discoveries & Learnings

| # | Tag | What |
|---|---|---|
| 1 | **Noteworthy** | **The banner is a wire format and the two renderers now disagree.** Measured precisely rather than assumed. `harness dd set/add/rm/build` **silently** rewrites the banner back while reporting `ok`; `harness dd build --check` false-fails `E422`. `harness dd validate` and `harness plan validate` are **unaffected** (degraded, exit 0, 0 errors, zero drift-class findings). That last measurement is why the split stayed narrow — it corrected an overstatement in the escalation chain. Ruled into the **RENDERER AUTHORITY SPLIT** guardrail (`plan.dd.md`, commit `1773470`). Recorded for handover in `assets/handover-notes.md`. |
| 2 | **Noteworthy** | **A silent-failure mechanism is never "informational".** The regression above was first escalated under that label; the facts were right, the triage was not, and it nearly buried the highest-severity item in the message. Severity belongs to the failure MODE, not to the confidence level. |
| 3 | **Deferred** | **CI's `package-smoke` job had been asserting a falsehood since `713a43d`** — `dd status` must answer `unconfigured`/exit 2. True while verbs were landing; the ledger flipped when the tenth registered. An escape from phase 2 (which updated the vitest smoke tests but not the workflow). Fixed here to assert the honest post-port truth; verified against a real installed tarball. |
| 4 | **Deferred** | **The baked overview points at `docs/how/dd/exemplar/`, which is not ported.** Verbatim upstream text describing files that live upstream. Not rewritten unilaterally — the rename ruling covered command strings, not claims about what ships. `docs/how/dd/README.md` names the gap and lists the runnable equivalents that DO exist. Needs a ruling: port the corpus, or amend the source paragraph. |
| 5 | Noteworthy | **`git clone --local` is refused on a shallow repository**, which is exactly what `actions/checkout` produces. The gate asks `--is-shallow-repository` first rather than cloning through a warning. Caught by testing the CI shape locally, not by CI. |
| 6 | Noteworthy | **`the-flow.json`/`the-flow.md` are forbidden paths and were dirty with o-prime's edits.** `git add -A` swept them into the stage twice; both times unstaged before commit. A blanket add is unsafe in a two-writer repo — check `git status` against the forbidden list before every commit. |
| 7 | Noteworthy | Shortening `harness dd …` to `dd …` reflowed several string literals under the print width, so `biome` failed `lint` on formatting twice. Mechanical, `just fix` resolves it — but a rename that changes string LENGTH is a formatting change too. |
